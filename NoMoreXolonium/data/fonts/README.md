# this folder is intentionally empty on this repository.

Arial is included with Windows (and also the game itself) and OpenSans is available to everyone from a variety of locations. i believe their inclusion here is redundant. also the copyright trolling is very much a real problem in the world.

conversion was done with FontForge.

# fonts and their uses
- `Xolonium.otf`: main menu, window titles, buttons, item card text, loading screens, resource display, location, NPC chatter, reticle texts
- `Oxanium-Regular.ttf`: notifications, sector contents, chat, mail text, basically any smaller text.
